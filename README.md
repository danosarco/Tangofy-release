## Cos'è questo repository

Qui trovi **gli installer ufficiali di Tangofy Desktop** per Windows, pubblicati nella sezione
[Releases](https://github.com/danosarco/Tangofy-release/releases). Non contiene il codice sorgente.

Se cerchi l'app, la guida o i piani, parti dal sito: **[tangofy.app](https://tangofy.app)**.

## Installare Tangofy Desktop

1. Scarica **`TangofySetup.exe`** dall'[ultima release](https://github.com/danosarco/Tangofy-release/releases/latest).
2. Avvia il file e segui l'installazione guidata.
3. Apri Tangofy, accedi con il tuo account e importa le cartelle con la tua musica.

**Requisiti**: Windows 10 o 11 a 64 bit. Per ascoltare brani da Spotify serve un account Premium.

> **Windows SmartScreen** potrebbe mostrare un avviso sui programmi poco diffusi.
> Scegli *Ulteriori informazioni › Esegui comunque*. Il file è quello pubblicato qui, nelle release di questo repository.

Per disinstallare: *Impostazioni › App › Tangofy* (oppure riavvia l'installer).

## Cosa fa Tangofy

- **Libreria**: importa intere cartelle (anche migliaia di brani in pochi secondi) e ritrova orchestra, cantante, anno e stile dai tag dei file.
- **Tande e cortine**: componi tande, scegli le cortine e costruisci la scaletta di una milonga.
- **Generatore di milonghe**: parti da uno schema (tango, vals, milonga) e lascia che Tangofy proponga la serata.
- **Suonare in sala**: volume uniformato tra i brani, passaggi tra le tande, suono da sala.
- **Pre‑ascolto in cuffia**: prepara la tanda successiva mentre la sala balla.
- **Schermo ballerini**: una vista pulita da proiettare con la tanda in corso.
- **Storico e PDF**: ritrovi le serate passate ed esporti la scaletta.
- **Spotify**: usa anche i brani dello streaming accanto ai tuoi file.
- **Funziona senza internet**: la musica resta sul tuo disco, la licenza viene ricordata.

## Desktop o Web?

| | Desktop (Windows) | Web |
|---|---|---|
| Musica letta direttamente dal disco | ✅ senza richieste di permesso | ✅ con le cartelle autorizzate nel browser |
| Importazione di grandi librerie | ✅ molto veloce | ✅ |
| Pubblicità | nessuna | dipende dal piano |
| Installazione | sì | no, basta il browser |

Il piano **Tangofy Completo** include sia la licenza Desktop sia il Web senza pubblicità. Dettagli su [tangofy.app/pricing.html](https://tangofy.app/pricing.html).
